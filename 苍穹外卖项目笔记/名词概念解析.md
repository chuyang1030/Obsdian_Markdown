## Maven项目
- 项目的核心配置文件是 `pom.xml`（Project Object Model），它包含了项目的坐标（groupId、artifactId、version）、依赖管理、插件配置、构建配置等关键信息。Maven 根据这个文件来管理项目的整个生命周期。
- 依赖管理是 Maven 的一大优势。在 `pom.xml` 文件中，通过声明依赖的 groupId、artifactId 和 version，Maven 可以自动从中央仓库（或配置的其他仓库）下载所需的依赖及其传递依赖（即依赖所依赖的其他库）。例如，当你添加了 Spring 框架的依赖后，Maven 会自动下载 Spring 所需的其他相关依赖库，大大简化了依赖管理过程。
- 而非Maven项目依赖通常需要手动管理，比如将所需的 `.jar` 文件复制到项目的某个目录（如 `libs` 文件夹），然后在 IDE 中手动添加这些 `.jar` 文件到项目的构建路径中。
