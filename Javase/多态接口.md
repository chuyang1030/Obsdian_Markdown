## 多态：
1.形式：出现在继承或者实现关系中。
2.定义:同一行为，具有多个不同表现形式
3.特点：  调用成员变量时：编译看左边，运行看左边
        调用成员方法时：编译看左边，运行看右边
4.关键字instanceof:（比如：a instanceof student）用来判断a是否是student或其子类，并返回true/false


- final:被final修饰的成员，值（地址）不能被改变，数组中,值可以改变，地址不变。
- 
- 权限修饰符:1.public
            2.默认
            3.protect
            4.private
            
- 代码块：
- 
-  static关键字:被static修饰的变量是属于类的，所有对象共有这个成员，可以直接用类.来访问。而没被static修饰的属于对象，在别的类中要先创建对象才可以访问。
- 
-  继承:铭记子类继承父类的标准写法。子类构造方法第一行默认的super()；

- 抽象类：
1. 必须重写实现的全部接口中所有抽象方法。
2. 如果一个类实现了接口，但是没有重写完全部接口的全部抽象方法，这个类也必须定义成抽象类。
3. **意义：接口体现的是一种规范，接口对实现类是一种强制性的约束，要么全部完成接口申明的功能，要么自己也定义成抽象类。这正是一种强制性的规范。**

- 接口----联想到abstract抽象（本质是更彻底的抽象类），里面的方法是要被重写的（方法是抽象方法，方法后面没有大括号，直接；结束）
Java中，接口与接口之间是可以多继承的：也就是一个接口可以同时继承多个接口。大家一定要注意：

**类与接口是实现关系**

**接口与接口是继承关系**

接口继承接口就是把其他接口的抽象方法与本接口进行了合并。

### 增强for：
- 介绍
    
    - 它是JDK5之后出现的,其内部原理是一个Iterator迭代器
    - 实现Iterable接口的类才可以使用迭代器和增强for
    - 简化数组和Collection集合的遍历
- 格式
    
    ​ for(集合/数组中元素的数据类型 变量名 : 集合/数组名) {
    
    ​ // 已经将当前遍历到的元素封装到变量中了,直接使用变量即可
    
    ​ }


- 重写toString方法：对象是int，String，等类型就不用重写（已经写好了），但自定义的对象类型就要重写不然就会打印地址（没啥实际用处）
